There is two button log in and sign up. IF you are a new user you may get alert when you trying to log in. So this is where the Sign Up page come in.

User have to key in their username, password, confirm password, their Age, Gender, weight, height to sign in.
when they done sign up, it will navigate them to the login page where we have to log in.
Log in will lead you to the dashboard page where you can set your own goals in order to track the progress.
There is also a chart bar where it show your protein, carbs and fat intake for the day which is the main nutrition our body wants to have. Refresh button is used to refresh whenever you added your meal.
